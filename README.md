# 棋慧（KIEI）

将棋の棋譜を **検討** し、**AIに解説** してもらい、**詰将棋** も解ける Windows 用ツールです。

- 盤で駒を動かすと、将棋エンジンが候補手と評価値を出します
- 気になる局面を、AI（Gemini / ChatGPT / Claude / Groq）が文章で解説します
- 棋譜全体を解析して、評価値グラフで形勢の流れを見られます
- 戦型（矢倉・振り飛車など）を自動で判定して盤の上に表示します
- 詰将棋モード：江戸時代の名作「将棋図巧」「将棋無双」200問を収録。自分の作った問題の余詰検査もできます
- 将棋の本やスクリーンショットの画像から、局面を読み取ることもできます

> 画面のスクリーンショットをここに入れます（`docs/screenshot1.png` など）

## 1. 必要なもの

| もの | 用途 | 必須？ |
|---|---|---|
| Windows 10 / 11（64ビット） | 動かす環境 | 必須 |
| Python 3.10 以上 | 棋慧を動かす土台 | 必須 |
| 将棋エンジン（水匠5など） | 候補手・評価値 | 検討機能に必須 |
| 詰将棋エンジン（KomoringHeights） | 詰将棋の余詰検査・解答 | 詰将棋モードで使う場合 |
| AIのAPIキー | 解説文を作る | 解説機能に必須 |

エンジンもAPIキーも無くても、盤を動かす・棋譜を読み込む・収録問題を眺めることはできます。

## 2. インストール

1. このリポジトリの「Code」→「Download ZIP」で取得し、好きな場所に展開します（例：`C:\tools\KIEI`）。
2. [Python](https://www.python.org/downloads/) をインストールします。**インストール画面の一番下の「Add python.exe to PATH」に必ずチェック**を入れてください。
3. 展開したフォルダの `setup.bat` をダブルクリックします。必要な部品が自動で入ります（初回だけ・数分かかります）。
4. `kiei.vbs`（または `start.bat`）をダブルクリックすると起動します。
   - 起動しないときは、同じフォルダにできる `error.log` の内容を確認してください。

## 3. 将棋エンジンを入れる

棋慧には将棋エンジンは**含まれていません**（ライセンスの都合で配布できないため）。別に入手して、場所を教えてあげる必要があります。

### 3-1. 検討用エンジン：水匠5（おすすめ・CPUだけで動きます）

「水匠5」は強く、GPU（グラフィックボード）が無いPCでも動きます。まずはこれがおすすめです。

1. [やねうら王の配布ページ（GitHub）](https://github.com/yaneurao/YaneuraOu/releases) の関連ページから、水匠5入りのやねうら王（Windows版zip）を入手します。
   - 入手先やファイル名は変わることがあります。「水匠5 やねうら王 ダウンロード」で検索して、**配布元が公式（作者の GitHub）であること**を確認してください。
2. zip を好きな場所に展開します（例：`C:\engines\suisho5`）。
3. 展開すると `.exe` が複数入っています。名前の末尾が CPU の種類を表します。
   - `avx2`：最近の Intel / 多くの AMD の CPU 向け（まずこれを試す）
   - `zen2`：AMD Ryzen 向け
   - `sse42`：古い CPU 向け
   - 起動に失敗するときは、別の名前のものに変えてみてください。
4. 棋慧の右上「設定…」を開き、**「エンジン（exe）」** の欄で、選んだ `.exe` を指定します。

### 3-2. GPUがある人向け：dlshogi（任意）

NVIDIA のグラフィックボードがある人は、ディープラーニング系エンジン **dlshogi** を使うと、より速く深く読めます。設定の仕方は水匠5と同じ（「エンジン（exe）」に指定）です。

> ※ 棋慧との動作確認がまだ済んでいません。確認後に導入手順を書きます。

### 3-3. 詰将棋用エンジン：KomoringHeights

詰将棋モードで「余詰があるか」「正解手順は何か」を調べるときに使います。詰将棋を使わないなら不要です。

1. [KomoringHeights のリリースページ](https://github.com/komori-n/KomoringHeights/releases) から、Windows 用のファイルをダウンロードします。
2. 展開して、好きな場所に置きます（例：`C:\engines\komoring`）。
3. 棋慧の「設定…」→ **「詰将棋用エンジン（exe）」** で、その `.exe` を指定します。

### 3-4. エンジンの設定値

「設定…」では、次の値も変えられます。分からなければそのままで構いません。

- **スレッド数**：エンジンが使うCPUの数。PCのコア数より少なめにすると、他の作業が重くなりません
- **ハッシュ(MB)**：エンジンが使うメモリ量。PCのメモリの 1/4 程度までが目安です
- **全局解析：並列エンジン数**：棋譜全体を解析するとき、同時に動かすエンジンの数

## 4. AI解説の設定

使えるAIは次の4つです。**どれか1つ**のAPIキーがあれば解説が使えます。

| AI | 特徴 |
|---|---|
| Gemini（Google） | 無料枠あり。まず試すならこれ |
| Groq | 無料枠あり。応答が速い |
| ChatGPT（OpenAI） | 有料（従量課金） |
| Claude（Anthropic） | 有料（従量課金） |

1. 使いたいAIの会社のサイトでアカウントを作り、「APIキー」を発行します。
2. 棋慧の「設定…」を開き、該当する **「○○ APIキー」** の欄に貼り付けます。
3. 画面右側の「解説する（○○）」ボタンで、解説する局面を選んで実行します。

**APIキーの扱いに注意してください**

- キーは **あなたのPCの `config.json` に保存されます**。このファイルは他人に渡さない・GitHub などに上げないでください。
- 有料のAIを使うときは、各社の管理画面で **月の利用上限を低めに設定** しておくと安心です。
- AIの解説は参考情報です。**間違いを含むことがあります**。最善手の判断はエンジンの評価値を優先してください。

## 5. 収録している詰将棋について

詰将棋モードには、次の200問が入っています。

- **将棋無双**（伊藤宗看・1734年）
- **将棋図巧**（伊藤看寿・1755年）

どちらも江戸時代の作品で、**著作権は切れています**。盤面と正解手順のみを収録し、現代の解説・コメントは含みません。

## 6. よくある困りごと

| 症状 | 対処 |
|---|---|
| 起動しない | `error.log` を確認。Python が PATH に入っているか確認 |
| 候補手が出ない | 「設定…」でエンジンの `.exe` が指定されているか。別のCPU種別の `.exe` に変えてみる |
| 解説が出ない | APIキーが入っているか。無料枠の上限に達していないか |
| 詰将棋の余詰検査ができない | 「詰将棋用エンジン」が指定されているか |
| タスクバーのアイコンが元に戻る | `kiei.vbs` から起動する（`.py` を直接開くと Python のアイコンになります） |
